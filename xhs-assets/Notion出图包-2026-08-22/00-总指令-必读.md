## 二、文字数据源

`30期选题清单-富化v3.md`：30 期 × 3 项目 = 90 张卡。每张卡含六件套：
定位 / 功能点 / 场景 / 判断句 / 图片要素 / 封面标题+封面判断句。

星标数、语言名直接照抄清单，禁止自己改。

## 三、字段映射（清单 → 模板占位符）

### 封面（每期 1 张，用 template_cover_v2.html）

| 占位符 | 填什么 |
|---|---|
| `<h1>` 正文 | 该期「封面标题」（清单里每期已写好，直接替换「今天值得点开的，只有 3 个。」这句） |
| `{{repoN_name}}` | owner/repo（如 public-apis/public-apis） |
| `{{repoN_desc}}` | 该项目「定位」的第一句，压缩到 ≤40 字 |
| `{{repoN_stars}}` | 清单里的 ★ 数（含千分位逗号原样抄） |
| `{{repoN_gain}}` | 该项目语言名（Python / TypeScript 等） |
| `.series` 文字 | 该期「封面判断句」（替换「每天更新」） |

### 项目卡（每期 3 张，用 template_repo_v2.html）

| 占位符 | 填什么 |
|---|---|
| `{{index}}` | 1/3、2/3、3/3 |
| `{{repo_name}}` | owner/repo |
| `{{title}}` | 从「场景」改写成 ≤16 字标题，必须含动词（参考 agent_instructions_v2.md 四字段法） |
| `{{sub}}` | 「定位」压缩到 ≤60 字：痛点一句 + 怎么用 + 得到什么 |
| `{{stars}}` | ★ 数原样抄 |
| `{{gain}}` | 「功能点」里最亮的一条，压成短语（如「免费API按类目索引」） |
| `{{language}}` | 语言名 |
| `{{take}}` | 「判断句」原样抄 |
