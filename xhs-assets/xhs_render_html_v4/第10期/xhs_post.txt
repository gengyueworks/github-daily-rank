我是悦。今天在 GitHub 挖到 3 个非常硬核但又极其好玩的开源项目，推荐给喜欢折腾的朋友：

BitChat 专为没信号断网的场景设计，利用蓝牙 Mesh 可以在离线状态下接力传消息，在地铁、户外或者特殊断网时特别管用。

Agency Agents 把一整套广告公司的分工做成了 Agent 矩阵，文案、策划、设计各司其职，一个人也能调度一支虚拟团队。

还有苹果官方出的 Apple Container，嫌 Docker 在 Mac 上太沉太占内存的，用它能以超轻量的虚拟机运行 Linux 容器。

好的开源项目总能在你想不到的角度，把技术玩出花来。
