## 三、字段映射（清单 → 模板占位符）

### 封面（每期 1 张，用 template_cover_v2.html）——全部固定，无需发挥

| 位置 | 填什么 |
|---|---|
| `<h1>` 正文 | 固定不变：「今天值得点开的，只有 3 个。」 |
| `{{repoN_name}}` | owner/repo（斜杠两侧加空格，如 `public-apis / public-apis`） |
| `{{repoN_desc}}` | 该项目的「封面短描」（≤14 字，一行放下，禁止加长） |
| `{{repoN_stars}}` | 清单里的 ★ 数（含千分位逗号原样抄） |
| `{{repoN_gain}}` | 该项目语言名（Python / TypeScript 等；空则写 —） |
| `.series` 文字 | 固定不变：「每天更新」 |

### 项目卡（每期 3 张，用 template_repo_v2.html）

| 占位符 | 填什么 |
|---|---|
| `{{index}}` | 1/3、2/3、3/3 |
| `{{repo_name}}` | owner/repo（斜杠两侧加空格） |
| `{{title}}` | 清单「卡片标题」原样抄 |
| `{{sub}}` | 清单「副文」原样抄 |
| `{{stars}}` | ★ 数原样抄 |
| `{{gain}}` | 清单「卖点标签」原样抄 |
| `{{language}}` | 语言名（空则写 —） |
| `{{take}}` | 清单「判断句」原样抄 |
