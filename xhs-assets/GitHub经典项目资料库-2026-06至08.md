## 一、AI 智能体 / Agent 生态（最热赛道）

### 1. anthropics/skills ★169,303 · Python
- **定位**：Claude 官方智能体技能公开仓库，模板、工作流全开源
- **亮点**：官方带头做开源，十七万星。想给 AI 定义「怎么做事的规矩」，这里是标准答案
- **值得说**：普通人也能让 AI 按自己的方式干活，不用从零摸索

### 2. msitarzewski/agency-agents ★145,377 · Shell
- **定位**：一套完整的「AI 代理公司」——从前端到社群运营每个环节都有专职智能体
- **亮点**：每个智能体带个性、有流程、交付可验证成果
- **值得说**：「一个人的公司，员工全是 AI」的极致形态

### 3. Panniantong/Agent-Reach ★71,516 · 智能体全网信息获取
- **定位**：给 AI 智能体装上「全网眼睛」：Twitter、Reddit、YouTube、GitHub、B 站多平台信息获取
- **亮点**：13 平台多后端路由，AI 调研/选题/情报的核心基础设施
- **值得说**：AI 从「只会答」到「会自己去看」的关键一跳

### 4. DeusData/codebase-memory-mcp ★38,855 · MCP 服务器
- **定位**：把整个代码库索引成持久知识图谱的 MCP 服务器
- **亮点**：智能体不用每次从头「读」项目，记忆可复用
- **值得说**：解决 AI 改代码「每次都要重新理解项目」的痛点

### 5. kepano/obsidian-skills ★46,064 · Agent Skills
- **定位**：教 AI Agent 使用 Obsidian 的官方技能包
- **亮点**：Obsidian 创始人 kepano 出品，CLI + 开放格式
- **值得说**：笔记库配上 AI，整理这步自动省掉

## 二、AI 生产力 / 落地工具

### 6. infiniflow/ragflow ★88,386 · Go
- **定位**：开源 RAG 引擎，把文档变成 AI 的知识库
- **亮点**：PDF 表格扫描件精准识别，融合智能体工作流
- **值得说**：治的是 AI「胡说八道、找不到重点」的痛点

### 7. unslothai/unsloth ★71,513 · Python
- **定位**：本地运行和训练大模型的 UI，支持 Qwen3.8、Kimi K3、DeepSeek-V4 等
- **亮点**：显存省 80%、训练快数倍，点一点就能跑
- **值得说**：普通电脑低成本玩转顶级大模型

### 8. microsoft/markitdown ★173,628 · 微软出品
- **定位**：PDF/Word/PPT/Excel/音视频一键转干净的 Markdown
- **亮点**：微软官方，文档预处理行业标准
- **值得说**：喂给 AI 之前，所有文档先过它

### 9. ToolJet/ToolJet ★39,082 · JavaScript
- **定位**：拖拽式搭企业内部工具/看板/工作流/智能体的平台
- **亮点**：连数据库拖组件就生成网页应用，可接 AI
- **值得说**：后台系统的活，交给拖拽

### 10. stablyai/orca ★44,202 · TypeScript
- **定位**：并行 AI 智能体的控制台（ADE），同时跑多个编程 agent
- **亮点**：用自己的密钥跑多个 agent，手机也能无缝接管
- **值得说**：今日涨星破千，多智能体协作是方向

## 三、开源经典工具（装机必备）

### 11. rustdesk/rustdesk ★120,636 · Rust
- **定位**：开源自托管远程桌面，TeamViewer 替代方案
- **亮点**：自己搭服务器，数据全在自己手里，连接飞快
- **值得说**：十二万星换来的，是远程控制不再受制于人

### 12. localsend/localsend ★87,973 · Dart
- **定位**：全平台局域网文件传输，AirDrop 的开源替代
- **亮点**：不注册不配对，同一网络秒传，数据不过服务器
- **值得说**：AirDrop 的围墙，被它拆掉了

### 13. OpenCut-app/OpenCut ★83,169 · TypeScript
- **定位**：开源版剪映，视频剪辑免费替代
- **亮点**：自动字幕、智能转场内置，本地运行无广告
- **值得说**：八万星的开源剪辑，本地运行没广告

### 14. 3b1b/manim ★91,045 · Python
- **定位**：3Blue1Brown 的数学动画引擎
- **亮点**：数学公式、几何图形变动画，科普/课件神器
- **值得说**：科普视频的天花板，原来是开源引擎
